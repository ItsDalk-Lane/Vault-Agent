# Vault Agent · Pi 原生引擎重构执行包

版本：1.1 · 2026-10-22 · 语言：简体中文

**最终目标：用户只安装一个 Obsidian 桌面插件，配置模型后即可聊天、调用工具和恢复会话。没有 Claude Code、Codex、OpenCode 或 Pi CLI 安装步骤，没有独立 Node.js 安装、PATH 配置或终端登录。**

本包供 AI 编程工具分多次会话实施。先读 [START_HERE.md](START_HERE.md)，不要先重构代码。详细设计在 `design/`；原子任务、阶段门槛、进度与交接在 `execution/`；项目拥有的接口建议在 `contracts/`；固定行为样例在 `fixtures/`。

## 已作出的关键决定

1. **使用 `pi-durable + pi-ai + pi-mcp + chord`；Durable 是唯一 Agent 调度器。** 不再在它外面运行 `pi-agent-core.Agent`，不运行 `pi-coding-agent.createAgentSession()`。这项决定是在加入持久化恢复、压缩、子代理要求后，对此前 Core + AI 建议的更新。
2. UI、领域消息、会话索引、Markdown 导出、技能管理、模型选择、权限和 Diff 界面保留；通过 `PiBackendProcess` 接入现有 `BackendProcess`。完整执行历史交给 Durable；现有消息存储成为可重建的展示投影。
3. 工具统一经过宿主拥有的确定性策略。Vault 内容只经 Obsidian API，外部文件复用 Durable 的 Pi 原生工具；策略与 I/O 双层检查。**提示词和模型的自我声明不授予权限。**
4. 所有当前渲染功能必须真实贯通。缺少供应商数据时显示明确不可用，不伪造思考、额度或成功状态。
5. 使用 Pi **1.3.0** 的已发布公开 API。Durable 是实验性组件，锁定版本；升级单独立项，不让实施 AI 顺手更新到 main。
6. 用户已确认的原打包/运行 PoC 为 **P00 已完成**。本包不要求重做；后续测试是新增功能的回归，不得冒充 P00 未完成。

## 读者和交付物

设计文档中的“必须”是验收约束，“默认”是确定的初值，“禁止”不能被实现工具自行绕开。`contracts/*.ts` 是本项目拟实现的接口契约，不是已部署的 SDK，也不是整套可运行插件。

`execution/STATE.json` 是唯一任务状态来源。每个任务必须有实际证据文件后才能标记完成。恢复下一次 AI 会话使用 `execution/prompts/RESUME.md`。执行器最多领取一个原子任务；完成后更新状态和 `execution/HANDOFF.md`，再决定是否领取下一项。

## 本包的边界

本轮已经修改当前工作树中的生产实现、测试和验收记录；没有提交、推送或发布。静态一致性检查只验证链接、依赖与记录，不能证明产品已经完成。实际构建、模型请求和 Obsidian 运行结果单独记录。原 PoC 的通过状态来自用户，不冒称本次重新运行。

任意 Shell / 第三方本地 MCP 都具有宿主进程权限，不能靠 cwd 或正则证明不会访问 Vault。默认严格模式禁止不透明进程调用；高级用户可在插件里明确开启“可信宿主执行”并逐次批准。启用后界面必须声明它**不是操作系统沙盒**。详情在 [外部工具设计](design/08-external-tools.md)。这不是额外安装依赖。

远程 MCP 是无额外安装的默认路径。可选 stdio MCP 调用用户已经拥有的绝对路径程序；插件不替它安装 npm/uv/Node，也不承诺第三方服务器零依赖。核心 Agent 从不因此依赖这些程序。
