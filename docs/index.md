# Vault Agent 使用指南

Vault Agent 是 Obsidian 桌面插件。安装插件并连接自己的模型服务后，即可通过聊天读取、搜索和修改笔记。插件自带执行引擎，不需要安装额外的 Agent 程序，也没有插件账号、付费套餐或托管模型服务。

模型服务和外部工具服务可能由第三方提供，并可能收费。使用云端模型时，回答所需的提示词和笔记内容会发送到你选择的模型服务；选择本地模型不代表所有外部工具也都在本地运行。
