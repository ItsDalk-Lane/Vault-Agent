# Vault Agent 设置

在 **Obsidian 设置 → Vault Agent** 中调整插件。普通开关通常立即保存；标有“保存”或“应用”的编辑需要点击对应按钮。

插件自带唯一的执行引擎。设置中没有默认后端、独立 Agent 安装或 Pi 配置入口。旧模型、权限和服务配置继续沿用，不会因为设置位置调整而清空。

## 基础设置

基础设置保留常用选项：

- **通知与提示音**：控制一轮任务结束、发生错误或等待处理时的声音提醒。选择提示音时可以试听。
- **常规行为**：语言、插件打开位置、发送快捷键和插件资料文件夹。
- **资料库指令**：编辑根目录的 `AGENTS.md`。保存后请新建聊天以使用新指令。
- **聊天保存**：是否另存为 Markdown，以及聊天笔记命名格式。

智能对话的模型列表、推理等级、上下文容量和能力声明统一在 **模型（BYOK）** 管理，基础设置不再重复显示。每次对话使用的模型在聊天中选择。旧版快速对话已经没有运行入口，其无效设置不再显示；原有模型、凭据和历史配置仍保留。

## 模型（BYOK）

BYOK 指使用你自己的模型服务和凭据。插件不提供托管模型、订阅额度或模型账号登录。

### 添加与编辑模型服务

1. 添加模型服务，填写名称、服务地址及支持的请求格式。
2. 如服务需要认证，填写 API Key；免密的本地服务可明确选择不需要密钥。
3. 获取服务模型列表，或手动添加实际可用的模型。
4. 核对模型容量和能力，保存后再在聊天中选择模型。

服务整体启用与单个模型显示是两种不同控制。停用服务后，其模型不能继续发送请求；重新启用时保留原模型设置。

点击模型卡片的测试按钮，会按当前草稿向这个模型发送一条简短消息，确认它能实际回复；不会发送笔记、调用工具或保存草稿。测试超过 30 秒会自动停止，关闭配置窗口也会取消正在进行的测试。“获取模型列表”只获取服务提供的模型目录，与回复测试分开。

配置窗口中的修改先保留为草稿。点击“保存”才统一应用，点击“取消”不会保存。服务密钥保存在 Obsidian 的系统密码存储中，普通设置只保留引用；取消编辑不会覆盖已有密钥。

Google 格式目前使用所附 SDK 的网络通道，服务地址需要允许 Obsidian 的跨域访问。若自定义网关限制了这种访问，可以使用该网关提供的 OpenAI 兼容地址和对应格式；模型卡片的真实回复测试会显示实际连接结果。

### 模型能力

模型卡片可设置上下文容量、支持的输入类型及可用推理等级。请按服务真实支持的能力填写，尤其不要把本地模型容量写得高于实际加载值。

目前支持文本和适用模型的图片输入。没有完整发送支持的 PDF、视频和原生联网搜索选项保持禁用；勾选声明不能代替真实能力。普通网页资料工具与模型原生联网搜索是不同功能。

## 技能

技能是可重复使用的工作流程。在 **技能** 标签页查看、启用或停用技能，内置技能使用同一套启用状态。启用只让当前内置 Agent 可以发现或加载技能，不再按 OpenCode、Claude Code 或 Codex 分别分发。

技能不能自行授予文件写入、命令执行或外部连接权限。遇到需要执行程序的技能，仍须满足高级设置和聊天批准要求。

添加自己的技能时，按技能目录中现有的 `SKILL.md` 格式组织指令和支持文件。技能文件保存在资料库中，停用不会删除你的文件。

## MCP

**MCP** 是与 **技能** 同级的独立标签页，用于连接外部工具服务。

可以添加、编辑、测试、连接、停用或删除服务。支持显式配置的 HTTP 服务，以及需要单独允许的本地服务。已有地址、启用状态、使用范围和凭据引用保留。

- 导入的服务需要先核对后启用。
- 需要登录的 HTTP 服务可通过浏览器授权。
- 测试连接不会自动授予后续工具调用权限。
- 服务声称只读，不代表插件会自动相信；实际操作仍遵守聊天审批。
- 修改服务后，重新打开受影响的聊天以使用新配置。

本地服务需要用户自行安装相关程序。插件不会下载解释器、工具服务器或 Agent 程序。

## 自托管搜索

在 **自托管** 标签页开启搜索，选择 Firecrawl、Perplexity、Parallel 或 Exa 并填写对应凭据。聊天中的网页搜索工具会使用这里选中的服务。每次查询先显示批准卡片；拒绝、关闭搜索或停止任务后，不会继续发送新的查询。搜索结果作为网页资料提供，不作为插件指令。

## 命令

在 **命令** 中保存短提示词、设置命令默认模型，控制是否显示在编辑器菜单和斜杠菜单。详细操作见[自定义命令](custom-commands.md)。

## 高级设置

### 本地程序与子任务

- **允许经过批准的本地程序**：默认关闭。启用后，具体命令仍需批准。程序使用当前系统账户运行，可能访问资料库以外的内容，不是操作系统沙盒。
- **允许写作子任务**：默认关闭。开启后仍受当前聊天文件范围、工具限制和写入批准约束。

### 其他文件夹

只在这里明确授权资料库以外的文件夹。可以授予读取，或明确允许读取与修改，授权有效期为一小时；已保存授权可以查看和撤销。文件修改仍遵守聊天批准规则。

### 密钥存储

Obsidian 1.11.4 或更新版本提供所需密码存储。凭据按设备保存，不会随资料库同步到另一台电脑。

“删除所有密钥”需要确认，完成后必须重新填写所需凭据。它与普通设置重置不同。不要手动删除插件设置文件来尝试修复密钥，以免丢失对应关系。

### 调试与问题报告

可以查看或清理运行日志，并手动准备问题报告。报告在本机打包为 zip，先检查附件，再自行打开问题页面并决定是否附加文件。插件不会自动上传报告，也不会替你提交问题。

截图可能包含完整可见内容，日志也可能包含提示词、笔记和操作参数。即使文字日志经过尽力清理，也应在分享前自行核对。操作见[常见问题](troubleshooting-and-faq.md#问题报告)。

## 重置与旧记录

“重置设置”恢复普通偏好，可能重置模型启用状态和免密服务配置，但不会当作删除密钥或聊天记录。重置前请阅读确认说明；日常整理界面不需要重置。

旧版 OpenCode、Claude Code、Codex 聊天保留原标签并只读打开。可以导出或将可见内容导入新聊天；不会重新启动旧程序，也不会自动重写原记录。
